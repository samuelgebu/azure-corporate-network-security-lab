# Azure Portal screenshot evidence

The [screenshots folder](screenshots/) is intended for screenshots captured from the project author's actual Azure account.

Screenshots may show resource-group, virtual-network, subnet, virtual-machine and network-security-group configuration. These are configuration records, **not automatic proof of a running deployment or successful connectivity tests**.

Before publishing, obscure public IP addresses, subscription identifiers, email addresses, credentials and tokens. Private lab addresses (for example, `10.20.1.4`) may remain visible.

No stock Azure Portal images or assistant-generated architecture illustrations should be used as authentic project evidence.
